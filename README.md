##  About This Portfolio

Welcome to my Technical Writing Portfolio. This repository contains documentation, examples, and practical work completed as part of my Technical Writing coursework.

The portfolio covers six important tools used for technical documentation, presentation creation, version control, and collaboration.

| S. No. | Topic | Description |
|---|---|---|
| 1 | [LaTeX](1-LaTeX/) | Document preparation and professional typesetting |
| 2 | [Beamer](2-Beamer/) | Creating academic presentations using LaTeX |
